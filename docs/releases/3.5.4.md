# 3.5.4 定制版

基于母库 zhaohongxuan/obsidian-weread-plugin 的 3.5.3（11a193b），合并母库新书架、收藏、书籍详情、阅读定位及同步错误处理，并延续此 Fork 的定制功能。

- 从网页版章节原文恢复摘录段落，仅在唯一、完整匹配时恢复，不猜测边界；模板负责引用格式。
- 阅读器 Cookie 使用编码请求头，登录变化清除缓存。
- 开启恢复分段时先验证 Cookie；桌面端过期后扫码验证再继续。网络异常不使用旧的有效状态继续同步。
- 章节不可读取时保留现有笔记，失败集中记录到同步日志，避免逐本弹窗刷屏。
- 保留「过滤注释角标」开关：恢复分段后过滤 `[数字]` 和显示为 OBJ 的 U+FFFC。默认关闭，用户已有开启状态保留。保留 Markdown 链接、双链和普通数字；正文中的独立 `[数字]` 也会被过滤。
- 移除旧过滤实现的正则后顾，兼容较早 iOS。

验证：TypeScript 检查、构建通过；完整测试 351 项通过、0 失败、0 跳过（包含无头 Chrome）；Curtains 真实插件只读生成《血色子午线》《巴黎评论》，段落和模板引用正常、无 OBJ。未运行笔记同步。

限制：部分书籍或章节仍可能因权限、网络、阅读器接口而不可获取原文，插件会保留原有笔记并报告失败。原文不能唯一匹配时不会保证恢复段落。直接安装母库更新会覆盖此 Fork 的定制功能。

安装附件：main.js、manifest.json、style.css；ZIP 内包含这三个文件。
